# PTZ Recorte — downloads

Controle de câmera PTZ pelo navegador: desenhe um retângulo no vídeo e a câmera enquadra ali.

**[Baixar a última versão](https://github.com/Tabernaculo-Campinas-Tech/ptz-recorte-releases/releases/latest/download/PTZ-Recorte.exe)** (`PTZ-Recorte.exe`, Windows, sem instalação).

1. Coloque o `PTZ-Recorte.exe` numa pasta e dê dois cliques.
2. Na primeira vez o Windows pode mostrar "O Windows protegeu o computador": **Mais informações → Executar assim mesmo**.

A partir da 1.3.0 o próprio programa avisa quando há versão nova e se atualiza com um clique (botão **Atualizar** no topo). Não atualize durante o culto.

Este repositório só guarda as versões publicadas. Elas são geradas automaticamente a partir do código, que fica num repositório privado.
